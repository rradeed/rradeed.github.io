# Retro OS Portfolio

A personal portfolio built to mimic a classic, CRT-style operating system. Designed with a focus on immersive aesthetics, interactive window management, and client-side web technologies.


##  Features
*   **Simulated BIOS Boot Sequence:** Sequential DOM injection with audio timing.
*   **CRT Monitor CSS:** Custom scanlines, RGB phosphor shadow masks, and screen curvature.
*   **Interactive Desktop:** Draggable, resizable modals mimicking classic OS window management.
*   **Live Taskbar:** Real-time clock and date rendering.

## 🛠️ Built With
*   HTML5
*   CSS3 (Custom animations, pseudo-elements, Flexbox)
*   Vanilla JavaScript (DOM manipulation, event listeners, audio handling)
